永続テーブル

btc_candles

1分足と集計済みの日足・週足

symboltext NOT NULL PK
interval_minutesinteger NOT NULL（1 / 1440 / 10080）PK
open_timetimestamptz NOT NULL PK
open, highnumeric(20,8) NOT NULL
low, closenumeric(20,8) NOT NULL
volumenumeric(30,12) NOT NULL DEFAULT 0
sourcetext NOT NULL

複合主キー: (symbol, interval_minutes, open_time)

candle_rollup_backfills

既存1分足からの日足・週足バックフィル状態

symboltext PRIMARY KEY
completed_attimestamptz NOT NULL DEFAULT now()

candle_import_months

月次アーカイブ取込台帳

symboltext NOT NULL PK
interval_minutesinteger NOT NULL PK
month_startdate NOT NULL PK
rows_importedinteger NOT NULL
imported_attimestamptz NOT NULL DEFAULT now()

複合主キー: (symbol, interval_minutes, month_start)

candle_import_days

日次アーカイブ取込台帳

symboltext NOT NULL PK
interval_minutesinteger NOT NULL PK
day_startdate NOT NULL PK
rows_importedinteger NOT NULL
imported_attimestamptz NOT NULL DEFAULT now()

複合主キー: (symbol, interval_minutes, day_start)

demo_users

デモ画面Basic認証ユーザー

usernametext PRIMARY KEY
password_hashtext NOT NULL
created_attimestamptz NOT NULL DEFAULT now()

パスワードはハッシュのみ保存。Web登録機能なし。

  • btc_candles の検索用インデックス: ix_btc_candles_time (symbol, interval_minutes, open_time DESC)。
  • テーブル間に外部キー制約はありません。台帳と足データは symbol・interval_minutes・期間を使ってアプリケーション側で対応します。
  • 月次・日次取込では、一時テーブル candle_import_stage をトランザクション中に作成し、足データと台帳を同一トランザクションで保存します。コミット時に一時テーブルは破棄されます。
  • 起動時に既存の1分足から日足・週足を一度だけ作成し、アーカイブ取込後とライブ足の更新時に該当バケットを再集計します。
  • 日足・週足の履歴取得は、バックフィル完了後に btc_candles.interval_minutes の集計済み行を読み込みます。
  • demo_users.password_hashにはASP.NET Core PasswordHasherの結果を保存し、パスワード平文は保存しません。ユーザー追加はCLIのみです。

接続・取込設定

ローカル設定: BtcApi/appsettings.json ConnectionStrings:MarketData
Host localhost / Port 5432 / Database btcdb
Docker Compose: docker-compose.yml ConnectionStrings__MarketData
Host db / Port 5432 / Database btcdb
履歴開始日 設定キー: HistoricalData:StartDate
Compose環境変数: HistoricalData__StartDate（現在値: 2023-01-01）
起動時処理 CandleDatabaseStartupService がスキーマを初期化し、Kraken直近足を補完後、アーカイブ取込を開始します。
スキーマ根拠: BtcApi/Infrastructure/Persistence/PostgresCandleRepository.cs、BtcApi/Infrastructure/Persistence/PostgresDemoUserRepository.cs。 この図はコード上のDDLを示し、稼働中DBへの接続・実データ照会は行っていません。
